# Portfolio Pack

This portfolio pack presents the final state of the synthetic enterprise healthcare estate utilisation intelligence platform. It is designed for review, interview discussion, and local demonstration without changing the underlying evidence.

The portfolio boundary is strict: evidence is synthetic, the decision status is `awaiting_governance_decision`, the approval status is `not_approved`, and engineering release readiness is `engineering_ready_with_conditions`.
