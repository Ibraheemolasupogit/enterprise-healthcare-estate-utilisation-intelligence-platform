# Demonstration Guide

This guide supports a local demonstration using synthetic evidence.

## Preparation

Run:

```bash
make assurance-full assurance-report release-evidence verify-release-evidence
make dashboard-check portfolio-check handover-check final-audit
```

## Suggested Narrative

Start with the problem framing, then move through lineage, utilisation, forecasting, scenario comparison, optimisation, simulation, financial caveats, communication evidence, and assurance.

## Dashboard

Start the dashboard locally with:

```bash
make dashboard
```

Use the dashboard to show how synthetic evidence is presented to different stakeholder needs. Emphasise that simulation resilience failures remain visible and that financial outputs are nominal planning evidence.

## Close

End on the governance status: `awaiting_governance_decision`, `not_approved`, and `engineering_ready_with_conditions`.
