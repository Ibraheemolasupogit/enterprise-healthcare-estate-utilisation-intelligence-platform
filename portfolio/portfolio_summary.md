# Portfolio Summary

The platform demonstrates an end-to-end synthetic healthcare estate intelligence workflow: source generation, ingestion, entity linkage, data quality, utilisation analytics, forecasting, scenario comparison, constrained optimisation, operational simulation, financial assessment, stakeholder communication, assurance, and final handover.

The portfolio does not present operational advice. It shows how analytical evidence can be assembled, tested, traced, and communicated with clear governance boundaries.

Current status:

- Decision status: `awaiting_governance_decision`
- Approval status: `not_approved`
- Engineering release readiness: `engineering_ready_with_conditions`
- Evidence source: synthetic data only

The strongest portfolio signal is not a single numeric output. It is the controlled path from synthetic data to caveated decision evidence, including the refusal to treat nominal financial impact as realised benefit while simulation resilience remains unresolved.
