# Interview Talking Points

- I designed the repository around deterministic evidence, not one-off notebooks.
- I separated analytical outputs from governance decisions so the synthetic evidence cannot imply approval.
- I used validation contracts, tests, and release gates to make the portfolio inspectable.
- I kept simulation failures visible because hiding them would weaken the decision record.
- I treated financial outputs as nominal impact estimates and did not convert them into realised benefits.
- I built dashboard and communication layers from persisted evidence rather than re-computing separate stories.
- I added final handover material so another reviewer can run and inspect the synthetic project locally.

The concise summary: this is a synthetic healthcare estate intelligence platform that demonstrates analytics delivery, evidence discipline, and responsible decision framing.
