# Limitations and Boundaries

This portfolio uses synthetic data only. It does not contain real patient, staff, finance, estate, or operational records.

Key limitations:

- Forecasting uses a short synthetic history.
- Simulation is simplified and not clinically validated.
- Financial values are nominal planning estimates.
- Operational mitigation has not been validated.
- Governance approval has not been granted.
- Dashboard screenshots are optional and must be captured only from a real local dashboard session.

Boundary statements:

- Decision status remains `awaiting_governance_decision`.
- Approval status remains `not_approved`.
- Engineering readiness remains `engineering_ready_with_conditions`.
- Milestone 14 does not alter analytical conclusions or evidence.
