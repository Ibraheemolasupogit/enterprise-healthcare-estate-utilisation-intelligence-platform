# Analytical Journey

The synthetic analytical journey moves from foundation data to governed communication.

1. Generate synthetic source data.
2. Build and verify the curated SQLite database.
3. Link entities and expose lineage views.
4. Run data-quality checks and reconciliation.
5. Calculate utilisation and underutilisation evidence.
6. Forecast demand with eligibility and uncertainty controls.
7. Compare estate scenarios under constraints.
8. Optimise constrained room allocation.
9. Simulate operational flow and resilience.
10. Assess nominal financial impact.
11. Create stakeholder communication evidence.
12. Run assurance, release gates, reproducibility checks, and manifest checks.
13. Package the final portfolio and handover materials.

The journey ends with a governed caveat: simulation resilience concerns and unvalidated assumptions mean the evidence is ready for review, not for implementation.
