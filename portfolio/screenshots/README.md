# Screenshot Capture Note

No static dashboard screenshots are included in this synthetic portfolio pack.

The dashboard can be run locally with:

```bash
make dashboard
```

Optional screenshots may be captured manually from a real local Streamlit session after `make dashboard-check` passes. Suggested captures are listed in `config/portfolio.yaml`.

Screenshots must not be mocked, edited to hide warnings, or used to imply governance approval. The decision status remains `awaiting_governance_decision`, approval remains `not_approved`, and the evidence remains synthetic.
