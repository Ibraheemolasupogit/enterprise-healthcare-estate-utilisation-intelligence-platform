# Operational Reports

This directory is reserved for operational-facing synthetic decision-support report outputs, such as workforce, room-flow, utilisation, or resilience summaries.

Reports in this repository are synthetic decision-support outputs. No approval, service change, or implementation recommendation is represented here.

Canonical generated utilisation and simulation evidence is stored under `outputs/utilisation` and `outputs/simulation`; this directory is a report audience placeholder and should not be filled with generated artefacts solely to satisfy tests.
