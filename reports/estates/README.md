# Estates Reports

This directory is reserved for estates-facing synthetic decision-support report outputs, such as estate portfolio, building, room, and capacity summaries.

Reports in this repository are synthetic decision-support outputs. No approval, estate disposal, relocation, or implementation recommendation is represented here.

Canonical generated estate, scenario, and optimisation evidence is stored under `outputs/utilisation`, `outputs/scenarios`, and `outputs/optimisation`; this directory is a report audience placeholder and should not be filled with generated artefacts solely to satisfy tests.
