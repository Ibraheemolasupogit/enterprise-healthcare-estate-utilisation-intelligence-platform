# Executive Reports

This directory is reserved for executive-facing synthetic decision-support report outputs, such as concise summaries of evidence, caveats, and governance status.

Reports in this repository are synthetic decision-support outputs. No approval, board decision, or implementation recommendation is represented here.

Canonical generated communication and assurance evidence is stored under `outputs/communication` and `outputs/assurance`; this directory is a report audience placeholder and should not be filled with generated artefacts solely to satisfy tests.
