# Financial Methodology

Milestone 10 provides deterministic synthetic financial and sensitivity analysis evidence. It compares the current estate baseline, Milestone 7 heuristic scenarios and Milestone 8 optimisation cases using existing evidence from ingestion, quality, utilisation, forecasting, scenarios, optimisation and simulation.

The framework uses `GBP` as a synthetic planning currency on a `2025/26` constant-price basis. Values are not current market prices, audited accounts or guaranteed benefits. The analysis horizon is five years with end-of-year discounting, configured annual cost escalation and configured benefit ramping.

Financial outputs are descriptive decision-support evidence only. They do not approve a case, guarantee savings or create a final implementation recommendation.

Milestone 11 displays these financial values in the dashboard with prominent non-realisability warnings. Nominal NPV and risk-adjusted NPV are shown separately so positive nominal values are not mistaken for approved or realisable benefits.
