# Communicating and Influencing Model

The planned evidence-to-influence workflow is:

```text
raw evidence
-> validation and linkage
-> current utilisation
-> demand forecast
-> feasible options
-> cost and risk analysis
-> audience-specific communication
-> challenge and response
-> revised recommendation
-> decision record
```

Technical evidence should be transformed into the level of detail each audience can use. Executives need decision
criteria, trade-offs, uncertainty and governance implications. Clinical audiences need service continuity, room
suitability and patient impact. Finance needs transparent assumptions and sensitivity. Estates needs room, building and
feasibility detail. Technical audiences need lineage, validation, reproducibility and model limitations.

Milestone 12 implements the model as synthetic communication evidence. It still does not invent real meetings, approvals,
stakeholder quotations or completed communications. It records synthetic challenge scenarios, evidence-grounded
responses and a non-approving decision record.
