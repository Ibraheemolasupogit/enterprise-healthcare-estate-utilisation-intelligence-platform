# Persistent Under-Utilisation

Persistent under-utilisation is configured as effective utilisation below threshold across a minimum number of observed
periods. The current threshold is `0.35`, with a six-month window, at least four below-threshold months and at least
three observations.

Protected specialist rooms remain visible in the flag table but are excluded from releasable-space classification.
The output is a descriptive analytical flag, not a closure, disposal or consolidation recommendation.
