# Release Evidence

Release evidence is exported to `outputs/assurance/` as Markdown, CSV and JSON. It includes the assurance run summary, check catalogue, check results, failures, warnings, reproducibility checks, security findings, documentation results, release gates, release manifest and release-readiness report.

The release manifest records project version, Python requirement, milestone status, upstream run IDs, configuration checksums, schema checksums, documentation checksums, evidence checksums, test summary, coverage summary, solver identity, simulation engine identity, dashboard identity, release gates, limitations, decision status and approval status.

Release evidence is local engineering evidence. It is not a production release, estate approval, operational readiness statement or financial realisability statement.
