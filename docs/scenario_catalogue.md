# Scenario Catalogue

## Baseline

Retains active rooms, buildings and existing service-room relationships. It is the reference case and is not labelled
optimal.

## Light Consolidation

Tests limited release of low-utilisation, non-protected, non-specialist rooms. It preserves contingency capacity and
flags any warning constraints for review.

## Site Consolidation

Tests selected service movement from an eligible site to another synthetic site where constraints allow. It records
manual-review dependencies and does not claim that a building should close.

## Hybrid Redesign

Combines selective room release, service rescheduling assumptions and remote-eligible activity adjustment while
retaining face-to-face floors, specialist capacity and forecast uncertainty.
