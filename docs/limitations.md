# Limitations

Current limitations:

- deterministic synthetic source extracts exist, but they remain fictional and compact;
- no real patient data is included;
- no clinical decision support is provided;
- no production deployment exists;
- no real financial recommendation is made;
- no real travel-time service is integrated;
- SQLite is local and reproducible, not production infrastructure;
- deterministic linkage is conservative and identifier-led;
- data-quality issues are detected and queued, not corrected automatically;
- utilisation metrics are descriptive and synthetic, with occupancy proxied from bookings;
- demand forecasting is implemented over only 24 synthetic monthly periods;
- scenario comparison uses deterministic heuristics and requires manual review before any real-world interpretation;
- optimisation uses synthetic coefficients and simplified workforce/accessibility contracts;
- simulation is synthetic and operationally simplified; it is not clinical validation.

Future limitations to preserve:

- cost assumptions must remain transparent and uncertain;
- accessibility and service continuity constraints must be validated locally;
- analytical outputs must not be treated as governance approval.

## Dashboard Limitations

The Milestone 11 dashboard is local, read-only and synthetic. It has no authentication, no real-time refresh, no public deployment, no external APIs and no final recommendation. Screenshots are not generated unless a deterministic local browser capture environment is available.

## Communication Limitations

Milestone 12 stakeholder objections are synthetic challenge scenarios. No real governance decision, approval, meeting, quotation or stakeholder agreement is represented. Outputs are Markdown, CSV and JSON only and do not send communications.

## Assurance Limitations

Milestone 13 release readiness is engineering evidence only. It is generated locally unless GitHub Actions are run remotely, and it does not deploy, publish, approve estate decisions, validate clinical safety or make financial value realisable.
## Financial Limitations

Financial values are synthetic, non-audited and not market validated. Operational resilience remains unresolved from Milestone 9, so nominal positive financial effects are not treated as realisable without mitigation. No result is a recommendation or approval.
