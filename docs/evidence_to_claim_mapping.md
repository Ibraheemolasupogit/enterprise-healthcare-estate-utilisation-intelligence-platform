# Evidence To Claim Mapping

Every major communication claim is mapped to an evidence source in `communication_evidence_map.csv` and `evidence_communication_claims`.

Mapped claim types include:

- simulation failure;
- workforce bottleneck;
- nominal NPV;
- risk-adjusted NPV;
- quality score;
- utilisation;
- forecast horizon;
- potentially releasable mathematical candidates;
- mitigation requirement;
- non-approval boundary.

Each claim records audience, source table, source run ID, source metric, interpretation rule, caveat and output document.
