# Release Gates

Release gates are engineering controls only:

- `GATE-QUALITY`
- `GATE-DATA`
- `GATE-ANALYTICS`
- `GATE-REPRODUCIBILITY`
- `GATE-DASHBOARD`
- `GATE-COMMUNICATION`
- `GATE-DOCUMENTATION`
- `GATE-SECURITY`

Gate statuses are `pass`, `conditional_pass`, `fail` and `not_evaluated`. A conditional pass records explicit conditions, such as synthetic data boundaries, failed operational resilience or non-realisable financial evidence.

Engineering release readiness does not constitute governance approval or operational implementation readiness.
