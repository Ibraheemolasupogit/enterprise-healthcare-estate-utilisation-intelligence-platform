# Challenge Response Methodology

Milestone 12 records synthetic challenge scenarios using this deterministic method:

```text
record challenge
-> identify evidence
-> assess support
-> revise interpretation where justified
-> preserve unresolved concern
-> update decision record
```

Challenge responses use statuses including `supported`, `partially_supported`, `not_supported_by_current_evidence` and `insufficient_evidence`. The current required revision changes an analytical interpretation from a financially attractive candidate to nominally financially positive but not realisable without operational mitigation and further validation.

This is not a change from approved to rejected because no option is approved.
