# Dashboard Interpretation

The dashboard is decision-support evidence only.

Data quality scores describe configured checks and open issues. Manual-review rows remain open until separately reviewed.

Utilisation values are synthetic analytical measures and should be read with protected-capacity, specialist-room and quality flags.

Forecasts use only 24 monthly observations. Room-level forecasts are not enabled, and intervals describe synthetic analytical uncertainty.

Scenario evidence is heuristic comparison only. It does not choose an implementation case.

Optimisation evidence may show mathematical optimality, but mathematical optimality is not operational approval.

Simulation evidence is prominent because all configured case/experiment resilience rows failed in the current evidence. Workforce bottlenecks dominate the operational constraint evidence.

Financial evidence separates nominal NPV from risk-adjusted realisability. Positive nominal NPV does not override failed simulation thresholds, and all cases remain `not_realisable_without_mitigation`.

No page generates a final estate recommendation.

Milestone 12 adds a communication page. It displays synthetic objections, challenge responses and decision-record status without approval controls or workflow actions.
