# Roadmap

## Milestone 11

Complete: Dashboard and Stakeholder Views. The milestone provides a local Streamlit app, dashboard checks, page smoke tests and dashboard documentation.

## Milestone 12

Complete: Communication and Influence Evidence. The milestone provides audience briefs, challenge responses, analytical revision evidence, a decision record and claim lineage.

## Milestone 13

Complete: CI/CD and Automated Assurance. The milestone provides assurance checks, release gates, deterministic release evidence and local workflow-equivalent validation.

## Milestone 14

Next: Final Handover and Portfolio Pack. Do not implement as part of Milestone 13.

| Milestone | Entry criteria | Major deliverables | Completion boundary |
| --- | --- | --- | --- |
| 1. Repository Foundation and Decision Framework | Empty or existing repository baseline inspected. | Structure, settings, CLI, docs, tests, CI. | No analytics implemented. |
| 2. Deterministic Synthetic Source Systems | Milestone 1 complete. | Synthetic source datasets, generation contracts, metadata and quality-issue catalogue. | No real data or downstream analytics. |
| 3. Database and Entity Linking | Synthetic source systems available. | SQLite source, staging, curated and evidence layers with deterministic linkage. | No utilisation scoring. |
| 4. Data Quality and Reconciliation | Curated database available. | Full quality rules, manual-review queue and reconciliation reporting. | No utilisation scoring. |
| 5. Utilisation Metrics | Linked and quality-scored synthetic evidence. | Tested descriptive metric definitions and outputs. | No forecasting. |
| 6. Demand Forecasting | Historical synthetic activity and utilisation evidence. | Forecast model comparison, eligibility and uncertainty. | No scenario approval. |
| 7. Scenario Appraisal | Metrics and forecasts available. | Completed option definitions, constraints and comparisons. | No optimisation engine. |
| 8. Optimisation | Scenario constraints agreed. | Completed constrained allocation options. | No automatic decision. |
| 9. Simulation | Optimisation candidate evidence available. | Deterministic operational room-flow simulation evidence. | No real-world approval. |
| 10. Financial and Sensitivity Analysis | Simulation, optimisation and scenario evidence. | Financial and sensitivity evidence. | No governance approval. |
| 11. Reporting | Analytical outputs available. | Audience-specific reports. | Synthetic evidence only. |
| 12. Dashboarding | Report datasets available. | Dashboard views and filters. | No production deployment. |
| 13. Governance Evidence | Reports and challenge process defined. | Challenge-response and decision record templates. | No fabricated approvals. |
| 14. Final Packaging | Demonstrator complete. | Reproducibility, docs and final QA. | Demonstrator only. |
## Milestone 10

Milestone 10 is Financial and Sensitivity Analysis. It prepares deterministic financial evidence for Milestone 11 dashboard and stakeholder views without producing an implementation recommendation.
