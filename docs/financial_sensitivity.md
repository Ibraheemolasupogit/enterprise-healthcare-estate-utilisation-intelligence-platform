# Financial Sensitivity

Milestone 10 runs deterministic sensitivity analysis across demand growth, implementation cost, transition cost, operational mitigation cost, benefit ramp, discount rate, cost escalation, forecast demand basis, simulation-risk adjustment and building-release timing.

Each dimension is evaluated at configured low, base and high values. Tornado-ranking data is exported as tabular evidence rather than plotted output.

Sensitivity results show which assumptions most affect NPV and five-year cumulative effect. They are not implementation recommendations.
