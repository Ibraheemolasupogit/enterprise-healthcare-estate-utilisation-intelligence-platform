# Local Operations

Core local commands:

```bash
make assurance-full
make assurance-report
make release-evidence
make verify-release-evidence
make portfolio-check handover-check final-audit
```

These commands operate on synthetic data and local evidence files. They should not be interpreted as governance approval.

Use `python3 -m estate_intelligence.cli project-summary` to print the current lineage and status summary without running analytics.
