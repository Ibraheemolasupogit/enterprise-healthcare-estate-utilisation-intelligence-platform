# Handover Checklist

- Root README identifies the project, evidence boundary, and validation path.
- Portfolio pack exists and is manifest-backed.
- Handover pack exists and is checkable.
- Mermaid diagrams describe architecture, lineage, governance, assurance, and dashboard stakeholders.
- Screenshot fallback note exists.
- Final audit covers Milestones 1 to 14.
- Governance statuses remain `awaiting_governance_decision` and `not_approved`.
- Engineering readiness remains `engineering_ready_with_conditions`.
- Evidence remains synthetic.

Validate with:

```bash
make portfolio-package final-audit
```
