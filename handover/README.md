# Handover Pack

This handover pack explains how to inspect, validate, operate, and maintain the synthetic estate intelligence repository locally.

The evidence boundary is unchanged: all analytical evidence is synthetic, decision status is `awaiting_governance_decision`, approval status is `not_approved`, and engineering release readiness is `engineering_ready_with_conditions`.
