# Analytical Controls

Controls include:

- Deterministic synthetic data generation
- Schema and configuration contracts
- Data-quality checks and reconciliation
- Run identifiers and evidence lineage
- Forecast eligibility controls
- Scenario and optimisation constraints
- Simulation thresholds and failure evidence
- Financial caveats and nominal impact framing
- Communication language controls
- Assurance gates and manifests

Milestone 14 adds validation around documentation, diagrams, and handover manifests only. It does not change synthetic analytical results.
