# Security and Privacy

The repository is designed for synthetic evidence only.

Security and privacy expectations:

- Do not add real patient, staff, finance, or estate records.
- Keep `.env.example` non-sensitive.
- Use local SQLite evidence for demonstration.
- Run `make scan-secrets` before sharing.
- Keep governance and approval language aligned to the current statuses.

The project includes no external service credentials and no real personal data.
